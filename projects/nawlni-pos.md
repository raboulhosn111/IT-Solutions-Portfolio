## Project Overview

**NawlniPOS** is a Windows-based Point of Sale (POS) and retail business management solution designed to streamline daily operations, centralize business information, and improve transactional accuracy.

The application integrates sales processing, inventory control, customer account management, payment tracking, daily reconciliation, and business reporting into a unified desktop environment.

Developed with an emphasis on reliability, operational efficiency, and practical usability, NawlniPOS addresses the day-to-day requirements of retail businesses while maintaining a structured and maintainable technical architecture.

---

## Business Challenge

Small and medium-sized retail businesses frequently depend on disconnected tools, manual calculations, and fragmented processes to manage their operations.

These challenges can result in:

- Inaccurate inventory and sales records.
- Difficulties tracking customer credit and outstanding balances.
- Time-consuming daily financial reconciliation.
- Limited visibility into business performance.
- Increased risks of data loss and operational disruption.

NawlniPOS was developed to consolidate these activities into a centralized business management application.

## Technical Architecture

NawlniPOS follows a database-backed desktop application architecture, combining a Windows-based user interface with business logic and persistent data storage.

| Component | Technology |
|---|---|
| Programming Language | C# |
| Application Framework | .NET |
| Desktop UI | Windows Presentation Foundation (WPF) |
| Database Engine | Microsoft SQL Server |
| Database Deployment | SQL Server Express / LocalDB |
| Operating Environment | Windows 10 / Windows 11 |
| Reporting | Application-generated operational reports |
| Data Protection | Database backup and recovery workflows |
