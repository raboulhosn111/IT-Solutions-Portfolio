## Featured Enterprise Project

# KNPC Talent Hub

### Employee Talent Discovery & Internal Engagement Platform

**Project Type:** SharePoint-Based Enterprise Communication Solution  
**Technology Focus:** SharePoint Online, Power Apps, Microsoft 365  
**Business Domain:** Corporate Communications & Employee Engagement

### Project Overview

The KNPC Talent Hub initiative focused on creating a centralized digital environment for presenting and discovering employee talents.

The solution was structured as a SharePoint communication site with organized talent categories, a searchable directory, and supporting application interfaces.

The initiative brought together enterprise collaboration technology, content organization, employee engagement, and user-centered digital experiences.

### Business Objectives

- Provide a centralized destination for employee talent discovery.
- Organize talent information into clearly defined categories.
- Improve access to employee talent profiles.
- Support internal engagement and recognition.
- Simplify navigation and information retrieval.
- Establish a structured digital experience.

### Information Architecture

The platform was organized around three primary talent pillars:

1. **Art & Culture**
2. **Literature**
3. **Sports**

Its principal information areas included:

- Homepage
- Talent Pillars
- Talent Directory
- Contact & Support

### SharePoint Implementation

The SharePoint solution used modern communication site capabilities, including:

- Structured modern pages.
- Content sections and web parts.
- Navigation and information organization.
- Talent category presentation.
- Directory-oriented content access.
- Corporate-aligned user interface design.

### Power Apps Integration

Power Apps was used to support structured talent directory interaction.

The application design included:

- Category-specific screens.
- Talent profile presentation.
- Search and filtering capabilities.
- Navigation between talent categories.
- Structured information retrieval.

### Project Responsibilities

My contributions included:

- Gathering and translating business requirements into digital solution specifications.
- Designing SharePoint site structure and navigation.
- Developing and configuring modern SharePoint pages.
- Supporting Power Apps interface and filtering logic.
- Organizing talent categories and directory workflows.
- Coordinating technical and content-related requirements.
- Refining the solution based on stakeholder feedback.

### Solution Value

The initiative demonstrated how Microsoft 365 technologies can be used beyond conventional document storage and communication.

It illustrated the practical use of SharePoint and Power Apps to support organizational engagement, structured content discovery, and business-specific digital experiences.

## Digital Transformation Methodology

My approach to enterprise technology solutions follows a structured lifecycle.

### Phase 1 — Business Requirements

- Understand organizational objectives.
- Identify operational challenges.
- Review existing workflows.
- Define stakeholders and user requirements.
- Establish solution scope.

### Phase 2 — Solution Architecture

- Evaluate suitable technologies.
- Define information architecture.
- Design application and workflow structures.
- Identify integration requirements.
- Consider security, access, and maintainability.

### Phase 3 — Implementation

- Configure enterprise platforms.
- Develop application interfaces.
- Structure business data and content.
- Implement workflow logic.
- Integrate supported Microsoft 365 services.

### Phase 4 — Validation

- Test functional requirements.
- Review navigation and usability.
- Validate data handling.
- Identify implementation gaps.
- Incorporate stakeholder feedback.

### Phase 5 — Deployment & Improvement

- Prepare solutions for organizational use.
- Support user adoption.
- Address operational issues.
- Refine functionality.
- Plan future enhancements.
